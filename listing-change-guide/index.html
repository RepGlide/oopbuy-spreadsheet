Listing Change Guide

Record visible changes to title, destination, image, options, price context, and availability.

Record what you see, not what you assume

A listing can change in six independent fields. Record each visible change against the current page, and keep the reason for the change separate from the change itself.

Title

Note whether the page title still matches the snapshot. A changed title is a visible change; it does not tell you why it changed.

Destination URL

Record the URL you actually opened. If the link now leads somewhere different, that is a change to record.

Image

Check whether the page still shows the same item as the snapshot's image reference. A different image is a change, not a verdict about the item.

Options

Recheck color, size, version, and any other selectable option. Record which options are present now versus in the snapshot.

Price context

Read the price in its current context — the option it belongs to and the state of the page. Record the context, not a bare number.

Availability

Note whether the option is still there to select. Availability is a field of its own and can change independently of the others.

Frame noteEach of the six fields can change on its own. A change in one does not imply a change in the rest.
✓Confirmation boundary: only a field you have actually re-read on the current page counts as rechecked.

A worked record

  1. Title: unchanged.
  2. Destination: opens the same page.
  3. Image: still the same item.
  4. Options: one size is gone now — recorded.
  5. Price context: re-read in its current context.
  6. Availability: still selectable.

Illustrated version check — not live monitoring or a verified listing.
