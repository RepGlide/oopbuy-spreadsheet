Snapshot vs Current Guide

Understand the time gap between the sheet record and the page, and which fields to confirm separately.

A record is a moment in time

A spreadsheet row holds what was saved at the time it was recorded. Between then and now, the page behind the link may have changed. The snapshot and the current page are two different versions of the same listing.

Snapshot

The snapshot is the label, image reference, and destination link the sheet captured. It is the starting point of a check, not a live answer.

Current

Current is what you see when you reopen the page now. Open it and read the title, destination, image, options, price context, and availability as they are at this moment.

Difference

Record only the visible changes you actually observe. Do not infer why they happened — the reason is a separate question.

Question

Keep whatever still needs confirming as a question. A question is honest; a permanent "verified" label is not.

Fields that need separate confirmation

  1. Title — is the page still called the same thing?
  2. Destination — does the link open the intended page?
  3. Image — does the page show the same item?
  4. Options — are the color, size, and version still as recorded?
  5. Price context — does the price still sit in the same context?
  6. Availability — is the option still there to select?
Frame noteOne field being newer does not prove the others are still valid. Each field is rechecked on its own.

A worked check

  1. Snapshot: the row names a bag with a destination link.
  2. Current: the page opens to the same item.
  3. Difference: the price context reads differently now — recorded, cause not guessed.
  4. Question: the material is not stated — left open.

Illustrated version check — not live monitoring or a verified listing.
